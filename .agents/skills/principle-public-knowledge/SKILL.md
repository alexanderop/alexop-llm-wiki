# One public knowledge collection

All notes and author profiles belong in `apps/wiki/content/public`. The owner has chosen a public professional wiki: source captures, concepts and saved answers use this collection by default. There is no private-note mode or separate publication audience.

Keep original source material and acquisition records in ignored `raw/`; do not copy full copyrighted works into notes. Raw files need a separate backup.

Log note changes in `docs/wiki-log.md`. Saving or editing public-ready notes does not authorize committing, pushing or deploying; do those only when requested.
